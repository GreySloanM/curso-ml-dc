# Python para Data Science & Machine Learning en 18 Días

Repositorio dedicado a documentar mi aprendizaje en **Ciencia de Datos y Machine Learning con Python**, a partir del curso de Federico Garay (Escuela Directa) en Udemy.

Aquí recopilo ejercicios, notebooks y proyectos prácticos, con el objetivo de reforzar mis habilidades en programación, análisis de datos, estadística y aprendizaje automático.

## Objetivos

- Fortalecer mis conocimientos de Python y sus aplicaciones en Data Science.
- Aprender a manipular, limpiar y transformar conjuntos de datos.
- Aplicar técnicas de análisis exploratorio de datos (EDA).
- Crear visualizaciones para interpretar y comunicar resultados.
- Implementar y evaluar modelos de Machine Learning.
- Explorar redes neuronales y técnicas de Deep Learning.

## Tecnologías y herramientas

| Categoría | Herramientas |

## Metodología de trabajo

Para cada día del curso se busca:

1. Revisar los conceptos teóricos.
2. Implementar los ejemplos y ejercicios en Jupyter Notebook.
3. Experimentar con el código y realizar modificaciones propias.
4. Documentar observaciones y resultados.
5. Registrar los avances mediante Git y GitHub.
